# 色彩方案库（维度 `F`）

八组预设。**每组是语义角色到色值的映射，不是一组"好看的配色"。**

选定后，锚点区记录的是角色表；页面描述里只写角色名（`主色`、`强调色`），
不写 HEX。这样改色只需要改锚点区一处。

## 角色定义

| 角色 | 承担什么 | 禁忌 |
|---|---|---|
| `背景` | 页面主底 | — |
| `次背景` | 表头带、侧栏、面板底色 | 不要用作大面积主底 |
| `主色` | 标题、结论句、表头文字、主要规则线 | — |
| `强调色` | 填充与标记：统计条、标识条、重点行底 | **多数情况对比度不足，不承载正文文字** |
| `强调文字` | 需要用文字表达强调语义时（强调色的深化版） | — |
| `次强调` | 第二方、对照序列、次要标记 | 不要和强调色等权使用，否则焦点丢失 |
| `正文` | 正文与表格内文 | — |
| `次要文字` | 注释、口径说明、来源行、页码 | — |
| `分隔线` | 分区规则线、表格外框 | — |
| `正向` / `警示` / `负向` | 语义三色：成立／需复核／风险 | 只在真有语义时用，不做装饰 |

**为什么强调色要配一个强调文字色**：饱和的橙、黄、青做填充很好看，但作为
小字号文字时对比度不达标。拆成两个角色，填充用亮的，文字用深的，语义一致
而可读性不塌。

## 1. 商务深蓝 `corporate-navy`

**适用于**：审批、选型、董事会汇报、咨询交付。正式、克制、可核对。
**若**内容需要科技感或深色场，**改用** `dark-terminal`。

```
背景 #FFFFFF · 次背景 #F2F5F9 · 主色 #0B2545
强调色 #FF6A00 · 强调文字 #B34700 · 次强调 #1E6FD9
正文 #1F2933 · 次要文字 #5A6B7B · 分隔线 #D8E0E8
正向 #2E7D32 · 警示 #F57C00 · 负向 #C62828
```

## 2. 中性石墨 `neutral-graphite`

**适用于**：不希望有品牌倾向的中立材料、研究报告、多方共用的模板。
**若**需要区分对立双方，**改用** `corporate-navy`（它的次强调更清晰）。

```
背景 #FFFFFF · 次背景 #F4F5F7 · 主色 #1C1F23
强调色 #E8A317 · 强调文字 #8A6100 · 次强调 #5B6B7C
正文 #2B3038 · 次要文字 #6B7480 · 分隔线 #DCE0E5
正向 #2E7D32 · 警示 #E08600 · 负向 #B3261E
```

## 3. 学术靛青 `academic-indigo`

**适用于**：研究、教学、论文汇报、知识分享。沉稳、低饱和、久看不累。
**若**场合是商业决策，**改用** `corporate-navy`。

```
背景 #FFFFFF · 次背景 #F3F4F8 · 主色 #2A3573
强调色 #C2410C · 强调文字 #9A3412 · 次强调 #5B7FC7
正文 #23262E · 次要文字 #676E7D · 分隔线 #DADDE6
正向 #35704A · 警示 #C67A00 · 负向 #A93226
```

## 4. 活力珊瑚 `vibrant-coral`

**适用于**：产品发布、市场活动、面向年轻受众的材料。
**若**场合是正式审批，**改用** `corporate-navy`——高饱和在审批语境里会被读作
不严肃。

```
背景 #FFFFFF · 次背景 #FFF5F2 · 主色 #1B2A41
强调色 #FF5A5F · 强调文字 #C1272D · 次强调 #00A8A8
正文 #24292E · 次要文字 #6E7781 · 分隔线 #E4E6E9
正向 #1F9D55 · 警示 #E8A317 · 负向 #D62839
```

## 5. 可持续绿 `sustainable-green`

**适用于**：ESG、能源、农业、健康、公益。
**若**内容与自然或可持续无关，**不要**为了"清新"而选它——语义色会误导读者。

```
背景 #FFFFFF · 次背景 #F1F6F2 · 主色 #14432A
强调色 #4CAF50 · 强调文字 #2E7D32 · 次强调 #00796B
正文 #1F2A24 · 次要文字 #5F6F65 · 分隔线 #D6E2D9
正向 #2E7D32 · 警示 #EF6C00 · 负向 #C62828
```

## 6. 深色终端 `dark-terminal`

**适用于**：技术发布、监控看板、开发者材料。**必须配深色场风格**
（`dark-tech`）。
**若**材料要被打印，**改用**任一浅色方案——深色底打印极耗墨且效果差。

```
背景 #0D1117 · 次背景 #161B22 · 主色 #E6EDF3
强调色 #2F81F7 · 强调文字 #58A6FF · 次强调 #00D4AA
正文 #C9D1D9 · 次要文字 #8B949E · 分隔线 #30363D
正向 #3FB950 · 警示 #D29922 · 负向 #F85149
```

## 7. 深色午夜 `dark-midnight`

**适用于**：主题演讲、发布会现场、大屏投影。比 `dark-terminal` 更柔和、更少
终端感。
**若**内容是密集数据表，**改用**浅色方案——深色底上的密排表格可读性差。

```
背景 #12141C · 次背景 #1C1F2A · 主色 #F5F6FA
强调色 #F0A500 · 强调文字 #FFC44D · 次强调 #7B8FF7
正文 #D6D9E3 · 次要文字 #9198A8 · 分隔线 #2C3040
正向 #4CAF7D · 警示 #E8A317 · 负向 #E5484D
```

## 8. 暖纸墨 `warm-paper`

**适用于**：长文阅读、案例、品牌故事，配 `editorial` 风格。
**若**材料以数字为主，**改用** `corporate-navy`——暖底会削弱数字的锐度。

```
背景 #FDFBF7 · 次背景 #F5F0E8 · 主色 #2B2622
强调色 #C0632B · 强调文字 #96461B · 次强调 #4A6C6F
正文 #33302B · 次要文字 #7A736A · 分隔线 #E0D8CC
正向 #4A7C42 · 警示 #C08A2E · 负向 #A63D34
```

## 自定义

用户给了品牌色时，不要硬塞进某个预设，直接构造：把品牌主色放 `主色`，按上面
的角色定义补齐其余角色，构造时注意两条——

**强调色和强调文字必须是两个值**，后者要能在小字号下读清。
**深浅要成套**：`背景` 与 `正文` 的明度差要足够大；`次背景` 只比 `背景` 深一点点。

## 推荐规则

按顺序看三件事：`E` 风格是否要求深色场（是则只能在 6、7 里选）；`A` 场合的
正式度（越正式越低饱和）；内容里有没有需要对立表达的两方（比价、竞品、正反）
——**有就必须确认 `次强调` 与 `强调色` 区分度足够**，否则读者分不清哪个数字
属于哪一方。
