# 视觉风格库（维度 `E`）

八种气质。风格只管**形状语言、装饰密度、留白节奏、纹理层次**。

**风格不指定任何颜色，不指定任何字体。** 颜色在 `F`，字体在 `G`。这条边界必须
守住——一旦风格里写死了 HEX 或字体名，风格库就退化成一堆改不动的硬编码，
也没法和其他色板、字体自由组合。

**风格和叙事骨架 `D` 正交。** 任何风格配任何骨架都成立。

---

## 选择规则

| 风格 | 气质 | 选择规则 |
|---|---|---|
| `swiss-minimal` 瑞士极简 | 严格模块网格，方角几何，大面积留白，近乎零装饰；靠细线分区和留白建立秩序 | 适用于咨询、审批、高端提案，内容以文字和结构为主。若页面需要承载密集数据表，改用 `data-journalism`。 |
| `data-journalism` 数据新闻 | 出版级信息密度，多栏网格，发丝分隔线，页脚来源行，超大关键数字 | 适用于财务、比价、研究、年报——数据本身是主角。若内容稀疏，页面会显空，改用 `swiss-minimal`。 |
| `editorial` 编辑出版 | 杂志式层级，主次分明的栏宽，引文与边注，图文交织 | 适用于长文叙述、案例、深度解读。若内容以数字为主，改用 `data-journalism`。 |
| `soft-rounded` 柔和圆角 | 圆角容器，轻微层次，柔和分隔，亲和不锐利 | 适用于内部沟通、培训、产品介绍，希望降低距离感。若场合是正式审批或对外承诺，改用 `swiss-minimal`。 |
| `dark-tech` 深色科技 | 深色底，高对比数据发光感，几何线条，终端质感 | 适用于技术发布、监控看板、开发者材料。**要求色板是深色场**，与浅色纸质色板不兼容。 |
| `blueprint` 工程蓝图 | 网格底纹，标注引线，剖面与尺寸线的工程语汇 | 适用于架构方案、施工与制造、系统设计。若内容不含结构或空间关系，这个风格会变成纯装饰，改用 `swiss-minimal`。 |
| `brutalist` 粗野 | 超粗字重，强烈色块对比，硬边界，故意的不精致 | 适用于需要强冲击的宣言、活动、态度表达。**正式商务场合慎用**，容易被读作不专业。 |
| `photo-editorial` 图像主导 | 大幅图像占据构图，文字压在图上或紧贴图边 | 适用于发布会、品牌、空间与产品展示。**要求有高质量图像素材**；素材不足时改用 `editorial`。 |

## 未收录的风格

ppt-master 的风格库里还有手绘笔记、水墨、剪纸、像素、复古海报、粘土玻璃拟态等
十种，本库没有收。原因是它们依赖纹理、手绘笔触或复杂自定义图形，**PowerPoint
原生难以可靠表达**，方案写了下游也做不出，反而制造预期落差。

如果你的下游环境能处理（例如会配合插图素材），照本库的格式补条目即可：一行
气质词加一条选择规则，同样不写颜色和字体。

## 混合

填 `custom` 并写 `风格说明`，讲清由哪几个各负责什么部位。例如：

```
风格: custom（swiss-minimal + data-journalism）
风格说明: 严格模块网格与方角几何，无圆角无阴影无渐变，靠贯通细线分区与大面积
          留白建立秩序；承载数据的区域收紧为多栏密排表格，配发丝分隔线、右对齐
          数字列、页脚来源行。强调色只做填充与标记，不承担正文文字。
```

**混合时要指派分工**，不要只写"两者结合"——下游需要知道哪个负责什么，否则会
平均化成一个没有特征的中间态。

## 与色板的兼容

选完风格再选色板 `F` 时留意一条：`dark-tech` 只能配深色场色板，其余七种默认
配浅色场。若用户想让浅色风格配深色板，问清楚是否要整体反色，别默默套用。
