# 排版（维度 `G`）

两件事：字体族分工，字号阶梯。

## 1. 字体族

**硬约束：只用下游环境大概率装有的字体。** 方案是给 PowerPoint 读的，指定一个
它没有的字体，结果是静默回退成默认字体，整套排版意图作废——而且没人会收到
警告。宁可用常见字体，也不要为了气质选冷门字体。

| 角色 | 中文首选 | 西文与数字 | 何时单列 |
|---|---|---|---|
| `标题族` | 黑体 / 思源黑体 Heavy / 微软雅黑 Bold | Arial Bold | 始终 |
| `正文族` | 微软雅黑 / 等线 | Arial / Calibri | 始终 |
| `数据族` | — | Arial | 材料含表格金额、规格列、需要竖向对齐的数字时 |

**为什么数据要单独一族**：等高数字（所有数字同高、同宽）才能在表格里竖向对齐。
正文中文字体的数字通常不等宽，金额列会参差。财务、比价、报表类材料必须单列
数据族；纯文字材料可以省掉。

**标题与正文用不同字体族是层级的一部分**。若只用一族，层级全靠字号和字重承担，
在中文里对比会偏弱。

**写法**：给完整回退链，不只给一个名字。

```
标题族: 黑体, Arial, sans-serif
正文族: 微软雅黑, Arial, sans-serif
数据族: Arial, 微软雅黑, sans-serif
```

## 2. 字号阶梯

给锚定值，不给区间。下游可在 **±2** 范围内微调而不算新层级——这是留给它的
推理余地，也是防止微调累积成漂移的闸门。

| 角色 | 承担 | 16:9 建议锚定值 |
|---|---|---|
| `封面主标题` | 仅封面 | 54–60 |
| `页标题` | 每页标题 | 32–36 |
| `副标题` | 封面副题、章节说明 | 26–28 |
| `导语` | 页标题下的一句结论 | 22–24 |
| `正文` | 主体文字、表格内文 | 18–20 |
| `数据` | 表格数字、图表标签 | 18–20 |
| `焦点数字` | 需要被记住的单个大数 | 44–52 |
| `注释` | 小标签、单位、次级说明 | 15–16 |
| `脚注` | 来源行、口径说明、页码 | 11–12 |

**这些是建议区间，最终每个角色只写一个值。** 例如确定「页标题 36」，不写
「32–36」。

**只声明真正会重复出现的角色。** 一份六页的比价材料通常用不到副标题；用不到
就删掉那一行，不要为了填满表格而声明。声明了却不用的角色，会诱导下游滥用。

**至少要有的四个**：页标题、正文、注释、脚注。其余按内容需要增补。

## 3. 使用纪律

**页面描述里只写角色名，不写数字。** 写「结论句用导语」，不写「结论句 24px」。
角色到值的映射只在锚点区出现一次。

**同页同级必须同值。** 一页里所有「正文」角色的块用同一个值，不允许因为
"这块内容多一点"就缩小——内容多要么精简，要么换页型，不是缩字号。

**超出阶梯的字号只允许出现在焦点数字上，且全文不超过两次。** 第三次出现说明
它已经是个重复角色，回到阶梯里给它一个正式名字。

## 4. 页面家具

跨页重复出现的固定结构元素——眉标、页码、页标题下的装饰线。归在排版维度里
顺带确认，写进锚点区的「页面家具」小节。

四行就够：

```
- 眉标: <两位章节号> · <章节名> · 左上 · 注释角色 · 次要文字色
- 页码: <当前页> / <总页数> · 右上 · 注释角色 · 次要文字色
- 标题装饰: 页标题下方一条通栏细线 · 主色
- 例外: 封面不带眉标与页码
```

**写格式，不写值。** 眉标和页码的内容每页都变，锚点区给的是模板；下游按页
自己填。这一点和字号阶梯不同——字号是固定值，家具是格式串。

**不是每份材料都需要。** 三五页的短材料、单页汇报、发布会用的展示型 deck，
页码和眉标反而是噪音。用户说不用就整节省略，不要为了完整而硬加。

**用了就要全篇一致。** 家具的价值全在重复——只有一半页面带页码，比全都不带
更糟。唯一合理的例外是封面和章节页，它们通常不带。

## 5. 中西文混排

中文材料里出现英文和数字时，不要为它们单独换字号——回退链里的西文字体会
自动接管字形，字号保持一致即可。**唯一的例外是数据族**，它本身就是为数字
选的。

行内强调（加粗、变色）不改变字号，只改字重和颜色。
